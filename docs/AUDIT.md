# აუდიტი: რა იყო არასწორი პირველ ვერსიაში და რა შეიცვალა

> სტატუსი: ეს აუდიტი **კოდის წაკითხვით** გაკეთდა. თამაში ამ გარემოში არ გაშვებულა (Godot-ის ჩამოტვირთვა დაბლოკილია), ამიტომ "მიზეზები" ქვემოთ დადასტურებული კი არა, **სავარაუდოა**, სანამ რეალურ მოწყობილობაზე არ შემოწმდება.

## დონის მექანიკები

- **ხიდი ჩამოშლით:** ფიცრები ირხევა 0.55 წმ-ის შემდეგ ვარდება და 3 წმ-ში ბრუნდება.
- **ყუთი:** იწევა (RigidBody2D) და ასე აღწევ მაღალ კიდეს (კიდე 128 px, ხტომა ~100 px, ყუთი 64 px).
- **ბერკეტი + კარი:** მიდი ბერკეტთან → გამოჩნდება კონტექსტური ღილაკი → კარი ადის.
- **ხაფანგები:** ეკლები, ხვრელები.
- **ფარნები:** საკონტროლო წერტილები (შენახვა + სინათლე).
- **ბოლოს:** თაღი ღია სინათლით, დასრულების ეკრანი.

## გაშვებული არ არის (პატიოსნად)

ტექსტურები, ანიმაცია და ხმები მართლაც დაგენერირდა და ნახე (სპრაიტ-შიტი, სცენის მაკეტი). თუმცა **Godot-ში არაფერი გაშვებულა**.
