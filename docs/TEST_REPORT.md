## ყველაზე სავარაუდო პრობლემები პირველ გაშვებაზე

1. GDScript-ის ტიპის/სახელის შეცდომა (Output პანელი ზუსტად მიგითითებს ხაზს).
2. პარალაქსის ფენების მდებარეობა (`background.gd` → `_layout`): თუ ხეები "ტივტივებს" მიწასთან, `GROUND_BELOW_CENTER` უნდა დაიხვეწოს.
3. განათება: `Level._modulate.color`, ფარნის `energy` — თუ ძალიან ბნელია/ნათელია.
4. ყუთის მოძრაობა (`Player.PUSH_SPEED`), ხტომის შეგრძნება (`JUMP_VELOCITY`, `GRAVITY`).
5. ჯოისტიკის მგრძნობელობა და ღილაკების განლაგება რეალურ ტელეფონზე.
6. `export_presets.cfg` პარამეტრები.
